# Joyee Study Review

Joyee 的小学复习网页，当前包含上海牛津英语 4B 和统编版/人教版四年级下册语文复习内容。

## 内容

### 英语 4B

- 12 个 Unit 总进度看板
- 单词复习与完整必会词听写
- 每个 Unit 10 道语法专项题
- 每个 Unit 10 道单元测试题
- 按登录姓名分别保存本地进度
- iPad 横屏、竖屏和桌面浏览器自适应

### 语文四年级下册

- 全册复习重点
- 8 个单元主题整理
- 字词、句子、阅读、古诗文专项复习
- 7 类常见习作提纲
- 考前检查清单和本地进度记录

## 发布

GitHub Pages 入口文件为 `index.html`，语文复习页面为 `yuwen4x.html`。

学习进度保存在访问者自己的浏览器本地，不上传到服务器。
